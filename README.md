Projekt powstał na bazie bookletu na studia artystyczne - dlatego jest w nimn tyle treści i html'a. 
Pierwsze deploymenty zostały zrealizowane ok. 24.11.2025 i od tego momentu jest rozwijany. Przez pierwsze kilka miesięcy był bazą do nauki css'a.
Javascript wtedy jeszcze mnie przerastał dlatego navbar i przyciski funkcjonują w oparciu o html i css. 
W wolnym czasie dopracowywałam stronę. Nawet po kilku tygodniach przerwy byłam w stanie po powrocie odnaleźć się i szybko przypomnieć sobie zależności.
Po semestrze zimowym na uczelni i zajęciach z OOP w c# postanowiłam zmierzyć się z javascriptem i tym razem próg wejścia okazał się całkiem przyjemny. 
Javascript to bardzo obszerny temat, ale mogę z pewnością stwierdzić, że pierwsze kroki za mną. 
Po krótkich ale irytujących zmaganiach udało mi się połączyć repozytorium z visual studio code z repozytorium na githubie, za pomocą git'a. 
W końcu nie muszę ręcznie, pojedynczo aktualizować stron, tylko mogę to zrobić jednym commitem - dlatego to repozytorium ma ponad 200 deploymentów, 
na szczęście ten okres już za mną.
